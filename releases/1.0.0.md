# PlexonCrates 1.0.0 — Full Release

The first complete PlexonCrates release establishes a focused Paper 26.2 crate system for the Plexon family.

## Highlights

- Basic, Rare, Epic, and Legendary crates are generated on first start.
- PlexonKeys keys work immediately, including complete items captured through `/keysadmin setitem`.
- A built-in fallback mirrors the PlexonKeys 1.1.0 default keys if PlexonKeys is temporarily unavailable.
- Preview GUI, roulette animation, single opening, bulk opening, native holograms, and particles.
- Weighted item/command rewards with calculated per-player chances.
- Exact in-game capture for Slimefun and other custom-item plugins.
- Admin GUI and direct commands for blocks, rewards, keys, reloads, statistics, and diagnostics.
- Keys are not consumed until every eligibility and inventory-safety check succeeds.
- Rewards are committed before cosmetic animation, preventing loss on close or disconnect.

## Runtime

- Paper 26.2
- Java 25
- PlexonKeys 1.1.0+ recommended; no hard dependencies

Download `PlexonCrates-1.0.0.jar` below and see the repository README for the five-step setup.
