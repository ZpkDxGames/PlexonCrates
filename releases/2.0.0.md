# PlexonCrates 2.0.0 — Safe, GUI-first administration

PlexonCrates 2.0.0 is the complete second-generation release by **Tonim (ZpkDxGames)**. It preserves the four familiar PlexonKeys-backed crates while replacing the mutable runtime core with guided editors, exact key lifecycle management, SQLite persistence, journaled openings, protected world linking, reward limits, pity, diagnostics, and reversible migration.

## Highlights

- Build and publish crates entirely in game through persistent drafts and validation.
- Capture custom physical keys and reward items without losing PDC, components, or custom metadata.
- Resolve PlexonKeys live templates first, then last-known-good cache and exact fallback.
- Reject forged lookalikes and diagnose exact-template collisions before publication.
- Combine items, console commands, XP, levels, and Vault money in reward bundles.
- Configure rarities, permission conditions, player/global limits, cooldowns, deterministic pity, messages, and presentation effects.
- Link unlimited protected blocks with the persistent Link Wand and native TextDisplay holograms.
- Use instant, roulette, reveal, or summary presentation without tying reward safety to a GUI.
- Review persisted opening history, audit records, provider state, database queue, schema, collisions, drafts, and unresolved journals.
- Search, clone, import/export, archive, and safely delete crate definitions.

## Safety and persistence

Every opening freezes its exact key template and outcome, writes a journal, and then revalidates state, permission, limits, key count, and inventory capacity on the primary thread. Failure before consumption costs zero keys. History, statistics, reward state, pity, and journal completion share one SQLite commit, and unresolved crash journals use manual review so command rewards are never replayed blindly.

Configuration reloads activate a complete validated snapshot or restore the previous one. Database work uses one bounded writer, while displays and particles use centralized managers.

## Upgrading from 1.0.0

Stop Paper and back up the complete `plugins/PlexonCrates/` directory before replacing the JAR. The first 2.0 start creates a timestamped YAML backup, converts definitions, and imports links/statistics. The SQLite import, migration marker, and converted-file commit form one rollback boundary and retries are idempotent.

Read [MIGRATION.md](https://github.com/ZpkDxGames/PlexonCrates/blob/main/MIGRATION.md) before upgrading an existing server.

```bash
sha256sum -c PlexonCrates-2.0.0.jar.sha256
```
