# PlexonCrates 4.5.0

PlexonCrates 4.5.0 is the stable Paper 26.2 / Java 25 release built from the mature normalized SQLite/runtime architecture on `main`.

## Stability and crash recovery

- Rebased final 4.5.0 work on the real stable codebase instead of the experimental 4.x rewrite that failed during server testing.
- Preserves the existing journal-first opening pipeline, durable Claim Inbox, normalized published definitions, single database writer, draft leases, API/events, PlexonCore integration, PlexonKeys provider integration, portable crates, milestones, rerolls, and Phoenix migration tooling.
- Targets the exact PlexonCraft runtime line: Paper `26.2.build.121-stable` and Java 25.
- Updates bundled SQLite JDBC to `3.53.4.0` for the Java 25 production runtime.
- Keeps PlexonCore and PlexonKeys as provided/soft runtime integrations and verifies they are not shaded into the distributable JAR.

## Exact-item fidelity

- Captured Base64 Paper item snapshots are now authoritative.
- YAML display-name, lore, glint, unbreakable and enchantment overlays are no longer applied after an exact snapshot is decoded. This prevents visible editing fields from corrupting foreign-plugin identity metadata.
- New exact captures perform a Paper-native `serialize -> deserialize -> serialize` byte-equivalence check before persistence.
- Normalized `ItemSnapshotCodec` captures use the same current-server round-trip gate while preserving the original SHA-256 of stored payloads.
- Existing stored snapshots verify their exact original SHA-256 before decoding; they are not silently reconstructed from material/name/lore.
- Delivery amount remains separate from the immutable amount-one template.

## Verification

The 4.5.0 release pipeline requires:

- Java 25 compilation against Paper 26.2.
- `mvn clean verify` with the full stable test suite.
- Zero discovered skipped tests.
- A single distributable `PlexonCrates-4.5.0.jar`.
- Embedded `plugin.yml` and bundled SQLite JDBC.
- No shaded PlexonCore or PlexonKeys runtime classes.
- SHA-256 generation and verification before GitHub Release publication.

## Upgrade

1. Stop the server completely.
2. Back up `plugins/PlexonCrates/` before replacing the JAR.
3. Replace the previous PlexonCrates JAR with `PlexonCrates-4.5.0.jar`.
4. Start Paper normally; do not use `/reload` for the upgrade.
5. Run `/pcrates diagnose` and `/pcrates validate` before enabling or changing migrated definitions.
6. Re-test at least one exact custom reward and one physical PlexonKeys key through a complete opening.

For production acceptance of third-party recipe ingredients such as CustomCrafting items, test the real item through capture, restart, preview, delivery and its originating plugin's recipe/recognition path. CI can verify byte-preserving persistence logic, but only the live server can prove another plugin's runtime recognition behavior.
