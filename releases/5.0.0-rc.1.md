# PlexonCrates 5.0.0-rc.1 — Phase 2 Premium Admin Test Lab

PlexonCrates 5.0.0-rc.1 is the Phase 2 premium candidate built on the certified 4.6.0 exact-item/opening/transaction baseline.

## Premium closure

- Adds a dedicated **Test & Simulate** entry to the existing crate editor without replacing its draft/publication flow.
- Adds deterministic non-granting dry selection for administrators.
- Adds bounded Monte Carlo simulation at 1,000, 10,000, or 100,000 rolls.
- Adds expected-vs-observed reward distribution reporting with absolute percentage-point deviation.
- Adds configured-distribution and player-context eligibility modes.
- Adds publication-readiness diagnostics beside the simulation controls.
- Rejects stale simulation output when the draft/revision changes before asynchronous analysis completes.
- Keeps exact reward ItemStacks intact by cloning display items only on the primary thread.

## Analytical safety contract

Simulation never calls the real opening, payment, delivery, journal, claim, milestone, reroll, command, economy, XP, or item-grant pipelines.

The analytical service receives immutable scalar probability snapshots only. Monte Carlo work runs on one bounded worker with a bounded request queue; there is no repeating per-player or per-crate task and no database write per roll.

The `CONFIGURED` mode represents enabled configured rewards normalized through the same 10,000-ticket probability allocator used by real selection. `PLAYER_CONTEXT` additionally snapshots current player permission/date eligibility on the primary thread. Dynamic player/global reward limits and alternative-reward fallback resolution are explicitly not simulated and are stated in the UI.

## Upgrade / staging

1. Stop the staging server.
2. Back up the complete `plugins/PlexonCrates` directory and SQLite database.
3. Keep PlexonCore 2.0.4 and a compatible PlexonKeys provider installed.
4. Replace the prior JAR with `PlexonCrates-5.0.0-rc.1.jar`.
5. Start Paper 26.2 on Java 25.
6. Run `/pcrates diagnose` and verify existing crate/key/database health.
7. Open a crate in the admin editor and use **Test & Simulate**.
8. Execute the runtime matrix below before any stable promotion.

## Rollback

Rollback remains stable `v4.6.0`. Stop the server before rollback and restore the backed-up PlexonCrates data directory/database if staging data was changed by normal crate gameplay or administration. The 5.0 analytical feature itself introduces no destructive schema migration.
