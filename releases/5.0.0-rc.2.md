# PlexonCrates 5.0.0-rc.2 — Pipeline 4 Reliability Candidate

This prerelease hardens the Phase 2 opening journal after production reported unresolved MANUAL_REVIEW rows.

## Journal/recovery
- schema 4 adds explicit journal version, crate revision, payment source/transaction, payment state, grant state, and recovery classification;
- existing schema-3 unresolved rows are preserved as legacy/manual-review evidence;
- a one-time `plexoncrates.db.pre-v4.bak` is created before schema migration;
- only schema-4 PREPARED rows that prove no payment/grant attempt occurred are safely cancelled on restart;
- terminal journal rows older than 30 days are compacted in bounded 1,000-row startup batches; unresolved evidence is never compacted;
- reward grant is preceded by a durable GRANT_ATTEMPTED boundary, so uncertain post-grant crashes remain manual review instead of being replayed blindly.

## PlexonKeys RC2
- PlexonKeys-backed virtual balances are read from the authoritative PlexonKeys service;
- virtual consume uses stable identity `plexoncrates:opening:<opening UUID>`;
- SUCCESS is followed by Crates' durable payment-commit boundary before reward work;
- INSUFFICIENT safely cancels without grant;
- DUPLICATE fails closed to MANUAL_REVIEW because PlexonKeys RC2 does not expose the original replay outcome;
- the synchronous durability latency is measured because PlexonKeys RC2 requires its API on the Paper primary thread.

## Delivery
- exact overflow claims are persisted without falling back to a world drop on persistence failure;
- opening finalization waits for pending claim persistence;
- player success acknowledgement occurs only after atomic opening finalization succeeds;
- command, money, XP, item and mixed grants are never automatically replayed from an ambiguous GRANT_ATTEMPTED state.

## Runtime certification required
Inspect the four existing production rows read-only before any mutation. They predate schema 4 and intentionally remain MANUAL_REVIEW unless an operator proves their payment/grant outcome. Do not merge or promote stable from CI evidence alone.
