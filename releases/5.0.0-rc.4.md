# PlexonCrates 5.0.0-rc.4 — Phase 3 Premium UX Closure

This candidate is a narrowly scoped GUI/UX correction on top of the integrated Phase 3 RC3 lineage.

## Fixed

- The registered Phase 3 player router now forwards `InventoryOpenEvent` into the existing legacy-surface redirect.
- Legacy non-admin Browser and Preview inventories are cancelled before display and replaced by the 54-slot Phase 3 Crate Hall / Preview UI.
- Physical linked-crate previews and legacy compatibility navigation therefore use the same player-facing probability and terminology rules as the accepted Phase 3 command surface.
- Selective player previews no longer fall through to the legacy percentage/jargon presentation path.
- Portable preview remains intentionally excluded because its issuance-specific state is owned by the accepted portable runtime flow.

## Preserved architecture

No changes were made to `OpeningService`, payment consumption, opening journals, recovery classification, ClaimService durability, exact ItemStack custody, PlexonKeys provenance, persistence/schema logic, statistics, limits, pity, replay protection, or migration behavior.

The four historical `MANUAL_REVIEW` journal rows remain untouched.

Canonical CI and release-candidate verification must pass for the exact RC4 source before publication. Runtime certification is not performed by this pipeline; the published artifact must be handed to Runtime Pipeline 7.
